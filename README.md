<h1><center>Electrocash - Sistema de control de creditos</center></h1>
<p>Sistema diseñador para gestionar de forma eficiente el proceso de préstamos.<br>
Permite registrar, monitorear y gestionar préstamos desde su solicitud inicial hasta su liquidación.</p>
